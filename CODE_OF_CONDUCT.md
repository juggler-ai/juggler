# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][cc]. By
participating — in issues, pull requests, discussions, or any other project
space — you agree to abide by its terms.

The full text is available at the link below; please read it before
contributing.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Enforcement

To report a concern, email **info@juggler.studio**. Reports are handled
privately; we will respond as promptly as we can and take appropriate action,
which may include warnings or removal from project spaces.
